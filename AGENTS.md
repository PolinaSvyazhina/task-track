# Инструкции для агентов

## Тесты

- Не создавать и не изменять тесты, пока пользователь явно этого не попросит.
- Не запускать тесты, пока пользователь явно этого не попросит.
- Запросы на разработку, исправление ошибок, рефакторинг или проверку проекта сами по себе не являются разрешением писать или запускать тесты.
- При генерации новых компонентов и других файлов отключать создание тестов, если генератор поддерживает такую настройку.
