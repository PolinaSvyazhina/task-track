О TaskFlow

TaskFlow помогает команде вести список задач, следить за их статусами и видеть, сколько работы ещё не завершено.

Как работать с задачами

  1. Откройте список задач, чтобы посмотреть текущую работу.
  2. Создайте задачу: укажите название, описание и приоритет.
  3. Откройте карточку задачи, чтобы прочитать полное описание и срок.
  4. По мере выполнения меняйте статус кнопкой в карточке.

Статусы задач

К выполнению — todo
Задача запланирована, работа ещё не началась.
В работе — in-progress
Задача выполняется.
Готово — done
Работа по задаче завершена.

Кнопка переключает статусы по кругу: «К выполнению» → «В работе» → «Готово» → «К выполнению».

Что означают поля задачи

  • Название: от 3 до 100 символов без пробелов по краям.
  • Описание: подробности работы и ожидаемый результат.
  • Приоритет: низкий, обычный или высокий.
  • Исполнитель: если не указан, видно «Не назначен».
  • Срок: если отсутствует, видно «Срок не задан».

В сводке незавершёнными считаются задачи со статусами todo и in-progress.
